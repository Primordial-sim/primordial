# Política de Seguridad

## Versiones soportadas

| Versión | Soporte          |
|---------|------------------|
| 0.3.x   | ✅ Soportado      |
| 0.2.x   | ⚠️ Solo bugs críticos |
| < 0.2   | ❌ Sin soporte    |

## Reportar una vulnerabilidad

Si descubres una vulnerabilidad de seguridad en **Primordial**, agradecemos tu ayuda para divulgarla de manera responsable.

### ⚠️ NO abras un issue público

Las vulnerabilidades de seguridad deben reportarse de forma privada para evitar que actores malintencionados las exploten antes de que podamos corregirlas.

### 📧 Método de reporte

**Opción 1: GitHub Security Advisories (recomendado)**

1. Ve a la pestaña **"Security"** del repositorio
2. Haz clic en **"Report a vulnerability"**
3. Rellena el formulario con los detalles
4. Se creará un advisory privado

### 📝 Información a incluir

- Descripción clara de la vulnerabilidad
- Pasos para reproducirla
- Impacto potencial
- Versión del software afectada
- Posibles soluciones (si las tienes)
- Prueba de concepto (opcional pero útil)

## Proceso de respuesta

| Plazo | Acción |
|-------|--------|
| **24-48 horas** | Confirmación de recepción |
| **7 días** | Evaluación inicial y clasificación |
| **30 días** | Corrección y parche (vulnerabilidades críticas) |
| **90 días** | Corrección y parche (vulnerabilidades moderadas) |

## Alcance

Esta política aplica a:
- Código fuente del motor de simulación
- Dependencias directas del proyecto
- Archivos de configuración críticos

No aplica a:
- Problemas de rendimiento
- Bugs funcionales (usar la plantilla de Bug Report)
- Problemas de usabilidad

## Reconocimientos

Agradecemos públicamente a quienes reporten vulnerabilidades de forma responsable. Los nombres de los reportantes serán incluidos en las notas de la versión donde se corrigió el problema (salvo que prefieran permanecer anónimos).

## Divulgación coordinada

Siguiendo las mejores prácticas de la industria:
1. Evaluamos y confirmamos la vulnerabilidad
2. Desarrollamos y testeamos un parche
3. Publicamos la corrección en todas las versiones soportadas
4. Divulgamos públicamente después de un período razonable
