Qué simula

Un ecosistema vivo donde las relaciones no están escritas: emergen.

🧬 Genética emergente

Genomas únicos con más de 20 rasgos heredables. Las poblaciones se adaptan solas, sin reglas fijas.

🌿 Ecología real

Ocho tipos de relación que emergen del perfil biológico, el genoma y el entorno de cada especie.

🦠 Epidemiología

Patógenos con variantes, contagio por carga viral, inmunidad cruzada y recuperación.

👥 Vida social

Matrimonios, familias, adopciones y genealogía completa con linajes a lo largo de generaciones.

🎛️ Control en vivo

Crea el mundo y modifica cualquier variable durante la simulación: fertilidad, longevidad, detección…

📊 Métricas

Instantáneas demográficas, genéticas, epidemiológicas, espaciales y cognitivas en cada tick.

Empieza en un minuto

Clona, instala y lanza tu primer ecosistema.

# clonar e instalar
git clone https://github.com/primordial-sim/primordial.git
cd primordial
python -m venv venv
venv\Scripts\activate
pip install -e .

# lanzar simulación
python launcher.py -p 200 -t 500
