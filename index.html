🧬 Genética Emergente

8 tipos de relaciones ecológicas que emergen de la combinación de perfil biológico, genoma y entorno.

🎛️ Control en Vivo

Crea mundos y modifica cualquier parámetro durante la simulación: probabilidad de embarazo, edad máxima, radios de detección...

🦠 Epidemiología

Sistema completo de enfermedades con patógenos, contagios, mutaciones, inmunidad y recuperación.

👥 Relaciones Sociales

Matrimonios, familias, adopciones, genealogía completa con linajes y árboles familiares.

📊 Métricas Multidimensionales

Análisis demográfico, genético, epidemiológico, espacial, cognitivo y genealógico en tiempo real.

🚀 Instalación rápida

git clone https://github.com/primordial-sim/primordial.git
cd primordial
python -m venv venv
venv\Scripts\activate
pip install -e .
python launcher.py

🎯 Tu rol: arquitecto de mundos

En Primordial no eres un espectador: eres el arquitecto del mundo. Creas las condiciones iniciales y luego puedes modificar cualquier variable en tiempo real mientras observas cómo el ecosistema responde a tus cambios.
